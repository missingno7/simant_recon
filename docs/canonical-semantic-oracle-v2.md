# Canonical semantic checkpoint v2

`canonical-semantic-oracle-v2` identifies the consolidated current source truth.
DOS and SDL3 consume the same `src/program.json` whole-TU inventory. Verified
semantic bodies, owner definitions, initial values and symbolic views are direct
canonical source; old snapshots/workflows are recoverable from Git.

The checkpoint includes clean-tree historical/static validation and 29 strict
semantic domains with differential source controls. Native database, RNG,
simulation, VGA, Save and Load checks pass against the current SDL3 build.
See [the consolidation report](consolidation.md) and current receipts under
`evidence/canonical/validation/` for exact identities, guarantees and limits.

This is a semantic checkpoint, not the functional DOS milestone. The independent
DOS link remains refused on twelve imports and ten semantic layout gates. DOS
full-game comparison, general native semantic closure and human acceptance are
pending. Native storage and adjacent-memory/unsupported-domain exceptions stay
explicit in `portable/platform.json` and the blocker ledger. Global native
16-bit expression promotion and intermediate-wrap equivalence also remain open.

`dos-semantic-oracle-v1` remains immutable at its original commit. It is not
retrofitted with the current corrections or architecture.
