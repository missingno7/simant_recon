## Build and verify

From the repository root, with Python 3.10+, MinGW-w64 GCC and the pinned SDL3
SDK/font reference installed as described in `portable/README.md`:

```powershell
python portable/tools/whole_program.py --compile --link
python portable/tools/build_whole_application.py --out build/whole-application-new
python portable/tools/run_whole_startup.py --application build/whole-application-new/simant-whole-sdl3.exe --out build/workers/whole_program/new-full-game --milliseconds 20000 --vga --input-script portable/tests/whole_program/application_input/full-game-vga-v1.txt
python tools/validate.py
python tools/link.py --reuse
python portable/tools/package_game.py --application build/whole-application-new/simant-whole-sdl3.exe --out build/releases/simant-preview-new
```

Outputs must be fresh directories. The default generated directory is used by
the application builder. The complete source conversion keeps original main,
startup, game/UI flow and shared state. The retired DOS heap module is replaced
at a host boundary. Current v17 links 97 original translation units and 111
native providers with zero unresolved symbols or duplicate owners. Compilation
and linking alone do not establish behavioral equivalence.
