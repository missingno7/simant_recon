# Standalone legacy save payload codec

This packet records a standalone ordered-payload codec, intentionally outside the default portable build and runtime. It implements the current S09 `fd_4E4B_0000` stream as 307 ordered records and 48,386 bytes. It does not implement file selection, filesystem writes, SaveGame dirty-state timing, LoadGame reset/rebuild, or transactional rollback.

`next7-binding-audit.json` compares every table pointer name and required byte extent with the diagnostic Next7 `RecoveredState` candidate. It resolves 300 rows by exact field name and sufficient declared extent. Seven rows remain unresolved and are not synthesized: `fd_50F6_0F46`, `fd_50F6_0FC6`, `fd_50F6_0F84`, `fd_50F6_1008`, interior bytes `(fd_3D57_087A + 20)`, `fd_50F6_103C`, and `fd_50F6_1048`. The interior row requires a genuine base-field binding with the recorded 20-byte offset. Next7 is a diagnostic generated candidate, not a production state API; consequently this packet does not claim a complete RecoveredState-to-save binding.

The codec takes caller-owned byte views for every row and fails if a binding is absent or too short. Encoding and decoding preserve table order, convert 2- and 4-byte elements to/from little-endian stream order, and allocate the encoded payload for the caller. Decode validates input length and all destination bindings before mutating any destination. Exact-length mode rejects a tail; source-compatible mode consumes the 48,386-byte prefix and ignores trailing bytes, matching the original `LoadGame` stream loop. The safer all-before-copy behavior is a portable codec property, not a claim about original DOS partial-read behavior.

The standalone test uses deterministic synthetic field buffers to check the full concatenation, all 307 offsets, round-trip, missing/short binding rejection, truncated input, exact-length rejection, and trailing-byte compatibility. The runner first checks that the C row schema exactly regenerates from the pinned source-derived inventory. It passes as `legacy_record_schema=PASS rows=307 bytes=48386` and `legacy_save_codec=PASS rows=307 bytes=48386 synthetic_roundtrip=yes`. Run `python portable/tests/save/run_legacy_codec_test.py` from the repository root. This is mechanical codec validation, not original-DOS byte-for-byte SaveGame differential evidence. The unavailable seven bindings and lack of a complete source-state mapping prevent that stronger comparison; no output file or oracle write result is claimed.

The authoritative format inventory remains [savegame-format-source-inventory-v1](../../../dialogs/evidence/savegame-format-source-inventory-v1/README.md), based on frozen `src/S09/m35F5.c`. `pins.json` hashes the source, inventory, generated Next7 candidate inputs, codec, tests, and audit output. The Next7 files are local ignored build inputs; regenerate them with the recorded source-reuse pipeline before relying on the audit, then compare hashes.
