# FindIndex native bounded-table guard evidence

This is a write-once source-only package for the bounded native host adaptation. It does not change or reclassify frozen DOS behavior evidence. The original DOS lower-bound search may read heap residue at `index[count]`; native C cannot safely do that. The adapter preserves the reviewed search and cursor pointer assignment, then returns null when the insertion rank equals the active count. Six DOS/native controls agree; two deliberately matching sentinel controls differ only because the original returns the one-past heap-residue sentinel while the host returns null.

The same guarded body was exercised in a native protected-page positive test and an unguarded access-violation negative control. The generated OpenDB/OpenIndex/DBRecall/LZSS/CloseDB runtime used four real databases (HCEGANT, compressed SHARED, raw SHARED, SOUND), with no artificial sentinel row. The DOS runtime calls are bounded to the eight cases recorded in `report.json`; actual database runtime tests were native. Scope is host memory safety and these bounded database paths, not historical BEHAVIOR_EXACT reclassification.

`report.json` records 58 exact before/after input identities and compiler/oracle identity. Reproduction requires the repository inputs at those paths, the separately installed compiler/toolchain and the original assets at the recorded paths; this package intentionally contains no original binaries, object files, compiler executables, or game assets. The report identifies the scratch output directory from the run.

The adapter is usable by the whole-module converter after reviewed overlays: `adapt_whole_source(source, module_path="src/root/m1986.c")`. It independently verifies the canonical TU digest and canonical FindIndex body, then verifies that restoring the canonical FindIndex body recreates the pinned TU exactly while the incoming FindIndex body matches the reviewed function digest. It inserts only the guard in that body.
