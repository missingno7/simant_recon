# NewGame and startup-window controlled flow differential

This packet compares original DOS execution of S15 `NewGame` and `SetDefaultWindows` with the selected native C bodies emitted by the next5 profile. The deterministic service fixture controls modal scenario selection, LoadGame results, window/resource operations, and RandYard. It compares return values, ordered calls, 11 named state words, every state snapshot at a controlled callback entry, and original RNG sentinels.

The run executed 128 NewGame cases: scenario values `202`, `203`, `204`, `206`, `205`, and `207`; flag values 0/1; modes 0, 10, and 11; open-window and zoom-result choices; 207 LoadGame retry-then-success; and 207 LoadGame success. Two direct SetDefaultWindows cases cover open and closed map-window branches. Every executed case matched. The gzip ledger has one complete input and observation row per case, including canonical observation hashes.

The RandYard boundary sets only MePlane/MeLocX/MeLocY to fixed fixture values and consumes no RNG. This tests NewGame’s flow after that call and does not prove RandYard or world generation. The legacy no-argument fastcall helper inputs are captured from each DOS call entry and replayed as explicit values in the native test service trace; their volatile values are not claimed to be independently generated by native C. The source `WinPrintf` implementation is the one-byte RETF stub; formatting output is outside this packet.

## Reproduction

Run `python portable/tests/recovered/newgame_flow_differential.py` after generating the pinned next5 profile. The committed packet includes the exact runner, probe, generated source/state files, profile provenance, producer wrappers, DOS VM dependencies, report, and ledger. The native DLL was retained in the local ignored evidence directory and is not committed; rebuild it from the pinned inputs with the command in the runner. `pins.json` records the SHA-256 and size of each committed file and the locally retained DLL. The report records the locked original executable and complete generated profile pins.
