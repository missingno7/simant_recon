## Details (condensed from the hand-back)
- F-1: verify_module locates each claim with its own delta; verify_extent only checks segment length,
  publics == claims and address tiling. Fix: require claim.frame_off - ext.start == public.obj_off
  for every claim (or bind the whole object segment as one span); cross-function WITHIN_GROUP_MISMATCH
  should fail the extent (not CROSS_FUNCTION_PENDING) at least when order is otherwise wrong.
- F-2: --extent start/end not tied to frame/object boundaries or function rows; extent_tail_reasons
  returns [] when nxt == end in the same frame and for gaps >= 16; --release does not require
  re-ownership. Fix: every row of the object range inside the extent; start/end tied to neighbouring
  owned objects plus fill; new @OFF keys need recorded origin evidence; report released-unowned.
- F-3: T4 asm proc with `db` body of original bytes; T4b `_asm _emit`. Current src/ is clean.
  Fix: refuse `_emit`, db/dw/dd between proc/endp, numeric branch targets, `org`, asm `include`;
  flag C initialisers >= 64 bytes without an OPAQUE-DATA marker; count flagged dumps separately.
  Notes: m0093.c:79 casts 0x046C0000L (046C:0000, not the BIOS tick) — likely faithful, comment it;
  S09 g_2776[128] is a MacBinary header dump (could be a struct); unflagged tables 29D6 g_7600/g_75E8,
  1629 g_1D0A..; 705 bytes of asm-module _DATA are db dumps; m290D.c:49 `_asm shr n,1` unmarked.
- F-4: 28 modules / 356 procs / 49,132 bytes generated by work/ovlA/d2a.py (capstone
  disassembly of the original emitted as MASM); not recorded in sources/manifest/journal; generator
  untracked; asm_evidence free text; MSC-shaped `push di; push si` procs inside S00:31AD (6),
  S01:3126 (1), S03:3258 (4) not classified per proc. Fix: per-module source_origin, generator in
  tools/ with pinned hash, measure asm_transcribed_bytes, validate asm_evidence probe paths,
  flag MSC-shaped procs.
- F-5: no placement-vs-placement overlap, SEGDEF alignment, link-order or reference checks. T2 (odd
  address, another module's string) and T2b (duplicate of 29B8's word; bytes counted twice) accepted.
- F-6: evidence classes of 606 applied code names: decisions CONFIRMED 196, xver CONFIRMED/HIGH only
  55, decisions HIGH 34, none 321 (263 nothing, 58 xver MEDIUM/LOW only). Conflicts: DigTileR
  (14EE:0647) vs xver HIGH SmoothEdgesR; RandTurn (0894:21C5) vs GetNewMode; RandYard (S08:059B) vs
  DoUserButton; lower: win_ObjAddr, db_PurgeHandle, DoPillar. Boilerplate evidence texts ("worker
  sim10F7 ... body matched" x36, "db worker ..." x26, "window worker ..." x14, "worker ovl08 ..." x16,
  the latter also on SGRand and myBeginSound). Sample: 12 meet policy, 16 single free-text anchor,
  1 unsupported (AddAntToBList). Fix: symbols.py rename must require the evidence class; migrate.
- F-7: runtime.verify_all packs oracle words for data targets (80 derived placements, 35
  single-anchor incl. XI*/XP*/XC* bounds, _edata, __doserrno, __ctype_, __osversion, STKHQQ,
  EMULATOR_DATA frame); toolchain.json "libraries": null. Fix: report count, DOSSEG link model,
  overlap checks, pin libraries.
- F-8: T5 --unsteer GetTriLatDist on unchanged 0798 accepted. Undeclared: S05:35F5 declaration
  layout chosen for the identifier count; S22:3BBD prototype placement + one-line `} else v++;` for the
  record break; 0250 load-bearing in-place draft ("keep 18").
- F-9: 108,199 / 202,797 exact C bytes in modules without extent; steered 8,119; pending 2,079; no

- F-10: 58 pinned hashes match. Headers unpinned; msc600ax INCLUDE from msc-6.00a-simantw (partial
