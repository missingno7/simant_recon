# Sound-control word storage evidence

`review.md` and `review.json` retain the unadmitted worker source audit.
`runtime-receipt.json` preserves the original measured artifacts and verbatim
outputs. Admission is recorded separately in `../storage-admission-v20.md`
and the root-reviewed binding/contract packets.

Run `python work/source-only-dos/sound-control-words-v20/replay.py` to rebuild
and execute all ten component cases under both RTLink profiles. Each replay
uses a fresh directory under `build/source-only-dos-research`, installs the
source-only input guard and remains unadmitted. The wrapper pins the durable
provider and probe against the admitted contract before execution. Avoid
direct execution of `probe.py`: that historical instrument names its original
scratch output directory.

These are six separate signed two-byte functional objects. The review makes
no historical link-layout, record-array, full game or human-acceptance claim.
